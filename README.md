# openbimrs/homebrew-tap

Homebrew formulae for OpenBIM.rs command-line tools.

```sh
brew install openbimrs/tap/openbim-ifc
```

| Formula | Source |
| --- | --- |
| `openbim-ifc` | [openbimrs/ifc](https://github.com/openbimrs/ifc), crate `openbim-ifc-cli` |

The formulae are generated by each project's release workflow from the
release's `SHA256SUMS` and committed here automatically; don't edit them by
hand.
